# Ameli

Ameli - языковая модель для агентных задач на русском языке: рассуждает, вызывает инструменты и доводит задачи до конца. Работает локально, на сервере клиента, данные никуда не уходят.

Модель в разработке. Разработка Smolnikov / CapyAgent.

Связанные модели: [Кивок](https://huggingface.co/smolnikov/kivok-0.3b) и [Мигом](https://huggingface.co/smolnikov/migom-2b) - модели быстрых решений.

---

Ameli is a Russian-first language model for agentic tasks: reasoning, tool use and multi-step work. Runs on-premises. Work in progress.
